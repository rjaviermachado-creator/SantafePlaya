# Fotos de Santafe Playa

Sube aquí tus capturas JPG, JPEG, PNG o WebP usando [Subir archivos](https://github.com/rjaviermachado-creator/SantafePlaya/upload/main/assets/gallery). Debes entrar con una cuenta con permiso de escritura. En GitHub, selecciona las fotos y confirma con «Commit changes». Las fotos aparecen automáticamente en la galería tras publicarse los cambios.

El nombre del archivo se usa como título: `2026-09-12-patrulla-nocturna.jpg` mostrará «patrulla nocturna». Usa nombres distintos para no sobrescribir fotos existentes. Comprueba que tienes permiso para publicar las capturas: este repositorio y las imágenes son públicos. No subas contenido privado ni imágenes de otras personas sin su permiso.

GitHub permite subir archivos de hasta 25 MiB desde el navegador; si una imagen pesa demasiado, comprímela antes de subirla.
